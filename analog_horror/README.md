# 停波 ― 外神竜一族 アナログホラー

`停波.mp4`（4分27秒・640×480）。深夜の放送終了後に割り込んだ臨時ニュースを、家庭用ビデオで録ったテープ、という体裁の映像。

設定資料 9-9「深層の見本」と同じ書き方をしている。観測する側（放送局と市）は理由を知らず、起きた現象だけを伝える。名前は一度も出ない。**新しい出来事を設定として確定させるものではない。**

## 映っているもの

| 現象 | 元にした設定 |
|---|---|
| 雨・川・波が止まる。投げた物が落ちてこない。「太陽に似た光」。金色の縦に割れた瞳 | ユリア（波／絶対停滞の核象／群れの太陽） |
| 排水口や用水路の「目」 | ヴォルの眷属（探し物もする） |
| 走っていく影 | アセラの影獣（先行偵察） |
| 市の外へ出ても、道がもとの場所に戻る | 燐の結界 |
| 理由のない恐怖 | ミリアの恐怖が波及 |
| 放送に割り込む緑の文字、地区を一つずつ調べる一覧 | レウネの情報掌握 |
| つり下げた物が同じ方向に傾く | ニルメの引力 |
| 地面からの脈拍 | ザイナの血肉共鳴（完全回帰は出していない） |
| 海水が球になって浮かぶ。差出人のない「おわび」の封筒 | テルエスの権限と資産 |
| 美術館の周辺だけ異常なし | エデル（興味がなければ来ない） |
| 沖の海面が一度だけ白く光る | フルル（迎えに行く） |
| 誰かを叱る大きな声。壊れた物がすべて元に戻る | ルリカ |
| 傘を差して歩く白い髪の人影（11本の傘） | 帰り道 |

## 作り直す

```
apt-get install fonts-noto-cjk fonts-noto-cjk-extra fonts-motoya-l-maruberi unifont ffmpeg
pip install numpy scipy pillow soundfile pyopenjtalk-plus
python3 build.py --work /tmp/teiha --out 停波.mp4
```

- `voice.py` ナレーション原稿と音声合成
- `timeline.py` 場面・テロップ・効果音の時間割（ナレーションの長さから決まる）
- `sound.py` 効果音・オルゴール・防災無線のこだま・雨・テープ停止（すべて合成）
- `picture.py` 各場面の絵と VHS の劣化処理
- `build.py` 全体の組み立て

アナウンサーの声を VOICEVOX にする場合は、VOICEVOX ENGINE を起動してから `--backend voicevox` を付ける。その場合はエンドカードの表記を「VOICEVOX:話者名」に直すこと。
