# 停波 ― 外神竜一族 アナログホラー

`停波.mp4`（640×480）。深夜の放送終了後に割り込んだ臨時ニュースと、街の防犯カメラの映像を編集したテープ、という体裁の映像。

雨が空中で止まった夜、ユリアたちが街じゅうを探しているのは、タコくん。ユリアたちに「ブス」と言い続け、テルエスのお金を数百万円持ち出してラーメンとエナジードリンクに使い、逃げてこの街に潜伏している。ユリアたちは怒っていない。狂おしいほど好きで、言い返されるほど火がつく。

設定資料 9-9「深層の見本」の延長として作ったもので、**新しい出来事を設定として確定させるものではない。**

## 流れ

1. 放送終了 → 臨時ニュース「雨が空中で止まっています」「太陽に似た光」
2. 防犯カメラ：自販機コーナーのタコくん。遠くからユリアの呼び声
3. 防災無線（市民を落ち着かせ、外に出さない呼びかけ）。途中からユリアの声に乗っ取られる
4. 電波ジャック「たずね人」。アナウンサーが読まされ、語尾をユリアが引き取る
5. 文字とノイズの嵐。家族の言葉と文字化けが画面を埋め、少し前の防犯カメラ映像に、港町へ逃げ帰る彼が一瞬映る
6. ご利用明細：レウネが、テルエスの口座から引き出された３１８万円の使い道を読み上げる。ラーメンの店と注文、エナジードリンクの自販機と味と本数、ホテル、ガチャ……。ヴォル・ルリカ・ミリア・燐・テルエスが口をはさみ、最後に潜伏先の部屋番号が明かされる
7. 「このテレビの前」。潜伏先の部屋、荒い息と速まる心音、止まる世界、金色の瞳、「みーつけた♡」
8. 部屋を飛び出す（アパートの外廊下の防犯カメラ）→ 駅前カメラ：止まった雨の中を走り、燐の結界にぶつかり、レウネの指示どおりの角へ追い込まれる
9. 防犯カメラ：糸で捕まり、引きずられていく。路上に残るヘッドホン
10. 婚姻届 → 「みつけた」「はい、おしまい」
11. 雨の中、傘の列に引きずられていくタコくん

恋愛・執着の表現は台詞、文字、婚姻届までにとどめ、露骨な描写はない。

## 作り直す

VOICEVOX ENGINE を `http://127.0.0.1:50021` で起動しておく。

```
apt-get install fonts-noto-cjk fonts-noto-cjk-extra fonts-motoya-l-maruberi fonts-unifont fonts-kouzan-mouhitsu ffmpeg
pip install numpy scipy pillow soundfile
python3 build.py --work /tmp/teiha --out 停波.mp4
```

- `voice.py` 台詞の原稿と音声合成（VOICEVOX）
- `timeline.py` 場面・テロップ・字幕・効果音の時間割（台詞の長さから決まる）
- `sound.py` 効果音・オルゴール・息づかい・悲鳴の加工・雨など（台詞以外はすべて合成）
- `picture.py` 放送側の場面と VHS の劣化処理
- `scenes2.py` タコくんをめぐる場面
- `film.py` 1コマを描く／`build.py` 全体の組み立て
- `tako.py` タコくん（正面）。参考画像をもとに、コードで描き起こした立ち絵。ポーズと表情を変えられる
- `family.py` 家族の人影（髪型・差し色・瞳の色だけの、顔のないシルエット）
- `assets/tako_sheet.png` 参考にした画像（映像には使っていない）
