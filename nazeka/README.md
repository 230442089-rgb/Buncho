# なぜか、走ってくる

日本のふつうの住宅街で、夜、なぜかアントン・シガーに追いかけられる 3D ゲームです。映画『ノーカントリー』（原作 コーマック・マッカーシー『血と暴力の国』）の登場人物をもとにした、**非公式のファンゲーム**です。映画の画像・音・台詞は使っていません。原作の筋とも関係ありません。

人物も町も、画像を使わずにプログラムで組んだ立体です。写真のような見た目ではありません。顔は実在の俳優に似せていません（髪型・服・道具で、それと分かるようにしてあります）。

**つかまると、暴力的な死亡場面があります。** 題の画面の「死亡場面」で、飛ばす設定にできます。

- 家畜用のボルト銃を額に当てられ、頭の中の断面で、脳が潰れる
- うしろから頭をつかまれ、首を一回転させられる

彼の方を向いてつかまると銃です。背を向けていたときは、まだ見た回数の少ないほうになります。

## きまり

- 彼は、あなたより速い。離れているほど、さらに速く走ってきます。まっすぐ逃げても、追いつかれます。
- ただし、角を曲がるのが下手です。あなたの姿を見失うと、最後に見た場所まで来て、立ち止まって見回します。間を空けて角を曲がるたびに、差が開きます。
- 見回してもあなたの姿がなければ、ありそうな方へ探しに走ります（外れることもあります）。
- 走ると、息が切れます。近くで走ると、塀のむこうでも足音で気づかれます。歩けば、音はしません。
- 家の玄関で、鍵を開けきれば、その日は終わりです。開けているあいだは動けません。
- 日がたつほど、家は遠く、彼は速く、勘もよくなります。

## あそぶ

`nazeka/index.html` をブラウザで開くと動きます（となりの `vendor/three.min.js` を読みこみます）。

| 操作 | キーボード・マウス | タッチ |
|---|---|---|
| 移動 | W A S D（または ↑ ↓） | 左下の棒 |
| 見回す | マウス（画面をクリックすると固定。固定できないときは、押したまま動かす）/ ← → | 画面をなぞる |
| 走る | Shift を押しながら | 棒を大きく倒す |
| 振り返る | Q / C を押しているあいだ | 「振り返る」を押しているあいだ |
| 鍵を開ける | 玄関の前で E / F / Enter / Space を押しつづける | 「鍵」を押しつづける |
| 中断 | Esc / P | 右上の Ⅱ |

## つくり

```
nazeka/src/page.html       画面の上の表示、題と結果の札、タッチ用の棒・ボタン
nazeka/src/style.css       見た目
nazeka/src/libs.json       three.js の置き場所（手もとの版 / 公開用の CDN）
nazeka/src/js/00_core.js   調整用の数値（PRM）、保存、入力
nazeka/src/js/01_audio.js  音（すべてその場で合成）
nazeka/src/js/02_town.js   町（道の格子、家、塀、電柱、街灯、「止まれ」、自宅）と、当たり・見通し
nazeka/src/js/03_body.js   人のかたち（骨組みと、走る・立つ姿）
nazeka/src/js/04_anton.js  彼の動き（追う・見回す・探す）
nazeka/src/js/05_death.js  二通りの死亡場面
nazeka/src/js/06_game.js   本体（あなたの操作、明かり、画面の流れ）
nazeka/src/js/07_main.js   起動と、入力のつなぎこみ
nazeka/vendor/             three.js r128（MIT ライセンス。three.LICENSE）
```

直したら、リポジトリの根で `python3 tools/build.py --game nazeka` を実行すると `nazeka/index.html` を作り直します。

手ごたえの調整は `nazeka/src/js/00_core.js` の `PRM` にまとめてあります（【】が仕様上の名前）。

アドレスの最後に `#debug` を付けて開くと、試験用の入口（`window.ATL`）が使えます。`ATL.Game.hold = true` でコマ送りを止め、`ATL.Game.step(1 / 60, n)` で n コマ進められます。
