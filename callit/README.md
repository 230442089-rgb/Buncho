# CALL IT ― 表か裏か

アントン・シガーに追いかけられるゲームです。映画『ノーカントリー』（原作 コーマック・マッカーシー『血と暴力の国』）の登場人物をもとにした、**非公式のファンゲーム**です。映画の画像・音・台詞は使っていません。

- あなたの鞄には発信機が入っています。彼は鞄へ、歩いてやってきます。走りません。
- あなたのほうが速く動けます。けれど、鍵を取る・給油する・電話をかけるといった、その場を動けない用事を済ませないと出られません。
- 鍵のかかった扉は、彼がボルト銃で錠ごと抜きます。扉のうしろに立っていると、抜けた錠に当たります。
- 二夜目からは、見通しのいい所に長くいると撃たれます。撃つ直前に狙いが止まるので、横へ動けば外れます。
- 鞄を置くと身軽になり、彼は鞄のほうへ向かいます。取られたら終わりです。
- つかまっても、一度だけ硬貨が決めます。表か裏か、言ってください。

三夜あります（モーテル → ホテル → 国境の橋）。

## あそぶ

`callit/index.html` をブラウザで開くだけで動きます（1 ファイルに全部入っています）。

| 操作 | キーボード | タッチ |
|---|---|---|
| 移動 | 方向キー / WASD | 左下の棒 |
| 走る | Shift / X を押しながら | 棒を大きく倒す |
| 決定（押しつづける用事、扉に鍵、鞄を隠す・拾う） | Z / Enter / Space | 「決定」 |
| 鞄を置く・拾う | C / B | 「鞄」 |
| 中断 | Esc / P | 右上の時間のあたり |

## つくり

```
callit/src/page.html       画面と、タッチ用の棒・ボタン
callit/src/style.css       見た目
callit/src/js/00_core.js   調整用の数値（PRM）、保存、入力
callit/src/js/02_gfx.js    ドット絵の道具、文字、減色ディザ（「事象のアトリエ」と同じもの）
callit/src/js/03_audio.js  音（すべてその場で合成）
callit/src/js/04_art.js    タイル、置き物、人物の絵
callit/src/js/05_maps.js   三夜ぶんの地図と、夜ごとの用事
callit/src/js/06_world.js  当たり、見通し、道のり、扉、通風口
callit/src/js/07_anton.js  シガーの動き
callit/src/js/08_game.js   本体（操作、用事、硬貨の場面、画面の流れ）
callit/src/js/09_main.js   起動と、入力のつなぎこみ
```

直したら、リポジトリの根で `python3 tools/build.py --game callit` を実行すると `callit/index.html` を作り直します。

手ごたえの調整は `callit/src/js/00_core.js` の `PRM` にまとめてあります（【】が仕様上の名前）。アドレスの最後に `#debug` を付けて開くと、試験用の入口（`window.ATL`）が使えます。
