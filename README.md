# 事象のアトリエ（ATELIER.EXE）

エデルが主人公の、liminal space / weirdcore な散策ゲームです。むかしのパソコンの画面（デスクトップ、タスクバー、窓）ごと再現してあり、その中のフリーソフトとして動きます。

- エデルは何も話しません。アトリエの外には果てのない空間が続いていて、歩いて、作品の素材を取り込みます。
- 離れた場所は、戻ってくると中身が変わっています。保存した素材が増えるとソフトが「更新」されて、つながる空間の種類が増えます（廊下、事務所、地下通路、夜道、畳の間、学校、プール、駐車場、駅、団地、田んぼ道、売場、待合室、未描画）。
- ときどき、偏愛でおかしくなったアセラが入ってきます。そのあいだ世界の運動は奪われて止まります（応答なし）。
- 止まっているものは見つかりません。動くと見つかり、つかまると**強制終了**します。保存していない素材は失われます。
- 作品は完成しません。

ゲームの画面の中に説明は出ません。説明は、デスクトップの「よんでね.txt」に全部書いてあります（最初の起動のときに自動で開きます）。

## あそぶ

`index.html` をブラウザで開くだけで動きます（1 ファイルに全部入っています）。

| 操作 | キーボード | タッチ |
|---|---|---|
| あるく | 方向キー / WASD | 十字ボタン |
| 取り込む（押しつづける）・画架で保存 | Z / Enter / Space | Ａボタン |
| そのほか | 窓のメニューとツールバー | 同じ |

キーは「設定 → キー設定」で変えられます。色数（16色 / 256色 / ハイカラー）、走査線、粒子、日付の写しこみ、音量は「設定 → オプション」にあります。

## つくり

```
src/page.html        デスクトップ・タスクバー・十字ボタンの骨組み
src/style.css        窓まわりの見た目
src/js/00_core.js    調整用の数値（PRM）、保存、入力
src/js/02_gfx.js     ドット絵の道具、文字、減色ディザ
src/js/03_audio.js   音（すべてその場で合成。音楽はなく、場所の鳴りと足音だけ）
src/js/04_sprites.js エデルとアセラのドット絵
src/js/05_picture.js 素材と、作品の絵の描き方
src/js/06_props.js   置いてあるもの
src/js/07_biomes.js  空間の種類（床・壁・置きかた・素材）と、更新の段階
src/js/08_world.js   果てのない世界（区画をその場で作り、遠い区画を捨てて作り直す）
src/js/09_asera.js   アセラの動き
src/js/10_game.js    ゲーム本体
src/js/11_shell.js   デスクトップ・窓・メニュー・ダイアログ・よんでね・強制終了の演出
src/js/12_main.js    起動
assets/portrait/     元絵から作った 16 色の画像（起動画面、バージョン情報、つかまる瞬間）
tools/build.py       src/ を index.html にまとめる
tools/make_portraits.py 元絵から assets/portrait/ の画像を作る
```

直したら `python3 tools/build.py` で `index.html` を作り直します（フォントの埋めこみに `pip install fonttools brotli` が要ります）。

手ごたえの調整は `src/js/00_core.js` の `PRM` にまとめてあります（【】が仕様上の名前）。空間の種類ごとの数値は `src/js/07_biomes.js`、場所ごとの音は `src/js/03_audio.js` の `SB` にあります。

アドレスの最後に `#debug` を付けて開くと、起動画面と「よんでね」の自動表示を飛ばし、F2 で来訪、F3 で視界の表示ができます。

## もう 1 本: CALL IT ― 表か裏か

`callit/` に、別のゲームが入っています（アントン・シガーに追いかけられる、非公式のファンゲーム）。説明は `callit/README.md` にあります。作り直すときは `python3 tools/build.py --game callit` です。
