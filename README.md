# 天下布鳥

自衛隊の統合任務部隊と総括指揮AI「ダリオくん」、そして近現代の科学技術をすべて覚えている文鳥・インコの参謀団が、永禄三年(1560年)の日本へ。
燃料と弾薬が尽きる前に石油を押さえ、戦国を平定し、海を渡って地球を日本にする、ターン制ストラテジーです。
スマートフォンの縦画面を基準に作ってあり、PCでも遊べます。

## 遊ぶ

`index.html` をブラウザで開くだけです(ビルド不要。通信するのはWebフォントと、戦闘の3Dアニメに使う three.js の読み込みだけ)。進行は端末に自動保存されます。

- 日本45地域 → 天下統一 → 世界54地域。すべてを自領にすれば勝利。
- 自衛隊の部隊は強力ですが、戦うたびに燃料と弾薬を使います。「石油蒸留」を研究して越後・秋田・遠江・蝦夷の油井を、「無煙火薬」と工廠で弾薬を国産化します。
- 鳥たち(7羽)に研究を割り振ると、高炉・蒸気機関から電子工学まで、産業革命を数十年で駆け抜けます。
- その先には、鳥たちの生きた時代と、まだ誰も見ていない未来があります:電子計算機、原子力、ロケット、情報網、深層学習、無人機、対話AI、光学兵器、核融合、汎用人工知能、軌道兵器、機動文鳥(全高四十メートル)。
- 「核兵器」と「超知能」だけは、司令が自分で命じたときにしか研究が進みません。核を撃てば、その土地は長く焦土になり、世界中に恐れられ、憎まれます。超知能が完成すると、AIによる完全な洗脳統治が始まり、後戻りはできません(結末が変わります)。
- 治めている土地には「民心」があり、年貢の軽減・種痘・学制・憲法など12の「施策」を布告できます。領地が広がるにつれて国の名が変わり(東富士駐屯地 → 富士鎮守府 → 東国政庁 → 日本国臨時政府 → 日本国 → 日本連邦 → 地球連邦日本 → 惑星日本)、各地の人々の声も、時代と民心で移り変わります。
- 降伏勧告・不可侵・通商・威嚇飛行など、戦わずに済ませる手もあります。
- 総括指揮AI「ダリオくん」が攻撃の編成と勝算を見立て、計算機で研究を後押しします。計算拠点の発電機は燃料を食います。
- 表紙とメニューの「年代記を見る」で、自衛隊と鳥たちとダリオくんの四百年ぶんの物語を、3Dの箱庭と戦闘の画でたどるアニメーションが流れます(全12章、自動送りで10分あまり。タップで次へ、長押しで止まり、章の名前を押すと章を選んで飛べます)。章ごとに、その年に何があったかの年表、各勢力がそのとき何を思っていたか、人口・死亡率・平均寿命などの統計が出ます。
- 「国勢」には、民の声・年表(自分の国の歩み)・国のようす(時代ごとに育つ町の3D箱庭)と、国のすがた(人口・経済力・死亡率・平均寿命・乳児の死亡・読み書き)があります。人口は地域ごとに、出生率と死亡率で季節ごとに動きます。
- 地球を統一したあとも、「このまま治めつづける」を選べば季節を進めつづけられます。
- 建設や部隊の移動を一つずつ指示するのが手間なら、「国勢」の「方針」でまかせられます。内政は「足りない資源を優先」「特定の資源を優先」「学問を優先」から選び、部隊の前進・守りの徴兵・編成もそれぞれ任せられます(攻める相手と外交は、いつも司令が決めます)。
- 学問所は、高等学校・大学・研究所へ格上げできます。建設は「鉄道」「内燃機関」で1季ずつ早くなり、資金を足して急がせることもできます。
- BGM は時代ごとに9曲(戦国の琴と尺八 → 行進曲 → ワルツ → スウィング → …)。効果音と同じく、その場で合成しています。メニューで音量を選べます。
- 攻撃すると3Dの戦闘アニメが流れ、制圧した地域には判子が押されます。効果音はすべてその場で合成しています。どちらもメニューから切れます。three.js を読み込めない環境では、戦闘アニメだけが省かれます。
- 音はブラウザの決まりで、最初のタップ(指を離した瞬間)から鳴り始めます。iPhone はマナーモードだと Web Audio が鳴らないため、既定で「動画と同じ扱い」に切り替えて鳴らします(メニューで切れます)。鳴らないときは、メニューの「音を試す」に状態が出ます。

## 中身

| ファイル | 役割 |
|---|---|
| `src/data.js` | 地域・勢力・技術・部隊・施設・参謀団・文言 |
| `src/lore.js` | 国号の移り変わり、施策、民の声、武将たちのその後、技術の時代、文化圏 |
| `src/engine.js` | 規則と状態(DOMに触れない。Nodeでも動く) |
| `src/ui.js` / `src/style.css` | 画面 |
| `src/birds.js` | 鳥とダリオくんの肖像、アイコン(インラインSVG) |
| `src/sfx.js` | 効果音と BGM(Web Audio で合成。音源ファイルなし。曲は音符の並びを文字で書いてある) |
| `src/battle3d.js` | 戦闘の3Dアニメ(three.js r128 を CDN から読む)。敵の文化圏ごとの軍勢と陣、大将、無人機・軌道砲・機動文鳥・核の演出 |
| `src/diorama3d.js` | 町の3D箱庭。研究が進むごとに、同じ町が時代を重ねていく |
| `src/chronicle.js` / `src/cine.css` | 年代記アニメ(箱庭と戦闘の画に、国号・施策・民の声の札を重ねる) |
| `src/mapdata.js` | 地図(生成物。手で編集しない) |
| `tools/build-map.mjs` | Natural Earth から `src/mapdata.js` を作り直す |
| `tools/japan-regions.mjs` / `tools/world-regions.mjs` | 地域の分け方(種点・国の割り当て) |
| `tools/build-artifact.mjs` | 公開用のページ断片 `dist/artifact.html` を作る |
| `test/sim.mjs` | ボットによる通しプレイ(例外・不整合・詰みの検査と、展開の速さの確認) |
| `test/rules.mjs` | 規則の点検(核・一揆・超知能・施策・国号・古いセーブの読み込みなど、ボットが踏まない道) |

## 開発

```sh
node test/sim.mjs normal 3      # 難易度「実戦」で3回、最後まで自動プレイ。-v で経過を表示
ASI=1 NUKE=1 node test/sim.mjs  # 超知能まで研究し、核も作って撃つボット(ほかに MAXATK=1、POL=none|all)
AUTO=scarce node test/sim.mjs   # 建設・徴兵・編成・移動を「おまかせ」に任せて完走するか(study、fuel、food なども)
node test/rules.mjs             # 規則の点検(状態を作って、核・一揆・超知能などを直接たしかめる)
node test/audio-check.cjs       # 効果音と BGM をすべて合成して、無音・小さすぎ・音割れがないか測る(Playwright が要る)
cd tools && npm install && node build-map.mjs   # 地図を作り直すとき
node tools/build-artifact.mjs   # 公開用の断片を作るとき
```

バランスの要は `src/data.js`(部隊・技術・地域の数値)と `src/engine.js` の収支・戦力の式です。数値を変えたら `test/sim.mjs` を3難易度で回して、ボットが完走すること(目安:日本統一まで約30ターン、地球統一まで約50〜70ターン、超知能は待てば55ターン前後)を確かめてください。

## 出典

海岸線と国境は [Natural Earth](https://www.naturalearthdata.com/)(パブリックドメイン)をもとにしています。戦国期の国境は、城下や郡の位置から近似したものです。人物・勢力は1560年ごろの史実にもとづきますが、物語はフィクションです。
