# 天下布鳥

自衛隊の統合任務部隊と総括指揮AI「ダリオくん」、そして近現代の科学技術をすべて覚えている文鳥・インコの参謀団が、永禄三年(1560年)の日本へ。
燃料と弾薬が尽きる前に石油を押さえ、戦国を平定し、海を渡って地球を日本にする、ターン制ストラテジーです。
スマートフォンの縦画面を基準に作ってあり、PCでも遊べます。

## 遊ぶ

`index.html` をブラウザで開くだけです(ビルド不要。通信するのはWebフォントと、戦闘の3Dアニメに使う three.js の読み込みだけ)。進行は端末に自動保存されます。

- 日本45地域 → 天下統一 → 世界54地域。すべてを自領にすれば勝利。
- 自衛隊の部隊は強力ですが、戦うたびに燃料と弾薬を使います。「石油蒸留」を研究して越後・秋田・遠江・蝦夷の油井を、「無煙火薬」と工廠で弾薬を国産化します。
- 鳥たち(7羽)に研究を割り振ると、高炉・蒸気機関から電子工学まで、産業革命を数十年で駆け抜けます。
- 降伏勧告・不可侵・通商・威嚇飛行など、戦わずに済ませる手もあります。
- 総括指揮AI「ダリオくん」が攻撃の編成と勝算を見立て、計算機で研究を後押しします。計算拠点の発電機は燃料を食います。
- 攻撃すると3Dの戦闘アニメが流れ、制圧した地域には判子が押されます。効果音はすべてその場で合成しています。どちらもメニューから切れます。three.js を読み込めない環境では、戦闘アニメだけが省かれます。
- 音はブラウザの決まりで、最初のタップ(指を離した瞬間)から鳴り始めます。iPhone はマナーモードだと Web Audio が鳴らないため、既定で「動画と同じ扱い」に切り替えて鳴らします(メニューで切れます)。鳴らないときは、メニューの「音を試す」に状態が出ます。

## 中身

| ファイル | 役割 |
|---|---|
| `src/data.js` | 地域・勢力・技術・部隊・施設・参謀団・文言 |
| `src/engine.js` | 規則と状態(DOMに触れない。Nodeでも動く) |
| `src/ui.js` / `src/style.css` | 画面 |
| `src/birds.js` | 鳥とダリオくんの肖像、アイコン(インラインSVG) |
| `src/sfx.js` | 効果音(Web Audio で合成。音源ファイルなし) |
| `src/battle3d.js` | 戦闘の3Dアニメ(three.js r128 を CDN から読む) |
| `src/mapdata.js` | 地図(生成物。手で編集しない) |
| `tools/build-map.mjs` | Natural Earth から `src/mapdata.js` を作り直す |
| `tools/japan-regions.mjs` / `tools/world-regions.mjs` | 地域の分け方(種点・国の割り当て) |
| `tools/build-artifact.mjs` | 公開用のページ断片 `dist/artifact.html` を作る |
| `test/sim.mjs` | ボットによる通しプレイ(例外・不整合・詰みの検査と、展開の速さの確認) |

## 開発

```sh
node test/sim.mjs normal 3      # 難易度「実戦」で3回、最後まで自動プレイ。-v で経過を表示
node test/audio-check.cjs       # 効果音をすべて合成して、無音・小さすぎ・音割れがないか測る(Playwright が要る)
cd tools && npm install && node build-map.mjs   # 地図を作り直すとき
node tools/build-artifact.mjs   # 公開用の断片を作るとき
```

バランスの要は `src/data.js`(部隊・技術・地域の数値)と `src/engine.js` の収支・戦力の式です。数値を変えたら `test/sim.mjs` を3難易度で回して、ボットが完走すること(目安:日本統一まで約30ターン、地球統一まで約60〜70ターン)を確かめてください。

## 出典

海岸線と国境は [Natural Earth](https://www.naturalearthdata.com/)(パブリックドメイン)をもとにしています。戦国期の国境は、城下や郡の位置から近似したものです。人物・勢力は1560年ごろの史実にもとづきますが、物語はフィクションです。
