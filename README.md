# 籠 ― 全て文鳥の所為です。

「全てあなたの所為です。」に連なる、いわゆる**界隈曲**の作法で書いたオリジナルのチップチューンです。
ファミコンの音源 (2A03) と拡張音源 VRC6 に相当する 8 チャンネルだけで鳴らしています。
曲も音源プログラムもこのリポジトリの中にあり、`python3 render.py` で一から作り直せます。

- **聴く**: [`dist/kago.mp3`](dist/kago.mp3) (3 分 29 秒)
- **歌詞を追いながら聴く**: `player/index.html` (下の「再生ページ」を参照)
- **DAW や歌声合成に持ち込む**: [`dist/kago.mid`](dist/kago.mid) (主旋律に歌詞つき)

題と名義は仮のものです (名義はリポジトリ名から取りました)。

## 構成

BPM 152。歌の旋律はすべてイ短調で書き、サビだけ区間ごとに移調しています。

| 時間 | 区間 | 調 | 拍子 | 中身 |
|---|---|---|---|---|
| 0:00 | 導入 | イ短調 | 4/4 | 再生ボタンの音、テープのヒス。オルゴールと時計だけ。上の声部が半音ずつ下がる |
| 0:07 | 前奏 | イ短調 | 4/4 | サビの主題をそのまま器楽で |
| 0:19 | A メロ | イ短調 | 4/4 | 陰旋法 (ラ・シ・ド・ミ・ファ) の淡々とした 8 分。前半は時計とオルゴールだけ |
| 0:45 | B メロ | イ短調 → | 4/4 | 変イ → 変ロ → ト7 と進み、2 拍の無音を挟んでサビへ |
| 0:57 | サビ | ハ短調 | 4/4 | 五度進行。最後はナポリの和音から名義フレーズ、全員で 4 分のキメ |
| 1:26 | 間奏 | イ短調 | **7/8** | 主題が 8 分ひとつ欠ける。4 小節目で音飛び、8 小節目でテープが止まる |
| 1:37 | A メロ | イ短調 | 4/4 | 歌の切れ目にノコギリ波が応える |
| 1:49 | B メロ | イ短調 → | 4/4 | |
| 2:02 | サビ | ハ短調 | 4/4 | 着地した瞬間に切れる |
| 2:29 | C メロ | イの都節 | **3/4** | わらべうた風の旋律とオルゴール。時計は 2 拍ごとに鳴り続け、裏でモールス信号 |
| 2:43 | 時報 | 440 Hz | 4/4 | 時計の刻みがそのまま時報になる。ピッ、ピッ、ピッ、ポーン |
| 2:46 | サビ | ニ短調 | 4/4 | 全音上げ。4 つ打ち、16 分の分散和音 |
| 3:15 | 落ちサビ | ニ短調 | 4/4 | 名義フレーズだけを倍の長さで |
| 3:22 | 後奏 | ニ短調 | 4/4 | 導入のオルゴールが戻り、テープごと止まる。最後に時報がひとつ |

界隈曲らしさとして入れたもの: オルゴールの導入、歌の 1 オクターブ下に重ねた声、
区間ごとの転調、変拍子、音飛びとテープ停止、モールス信号、時報、
サビ終わりの「全て〇〇の所為です。」、そして唐突な終わり方。

## 音源

1 チャンネル 1 音、音量は 4 bit、エンベロープは 60 Hz のフレーム単位という実機の制約をそのまま守っています。

| ch | 音源 | 役割 |
|---|---|---|
| P1 | 2A03 矩形波 1 | 主旋律 (歌) |
| P2 | 2A03 矩形波 2 | 主旋律の 1 オクターブ下 / モールス信号 |
| TRI | 2A03 三角波 (32 段の階段波) | ベース / 時報 |
| NOI | 2A03 ノイズ (15 bit LFSR) | ハイハット、スネア / 時計の音 |
| DMC | 2A03 ΔPCM (1 bit、33.1 kHz) | キック、スネアの胴、タム |
| V1 | VRC6 矩形波 1 | オルゴール、分散和音 |
| V2 | VRC6 矩形波 2 | 対旋律 / 高速アルペジオの和音 |
| SAW | VRC6 ノコギリ波 (7 段の階段波) | ベースの補強 / 持続音 / 合いの手 |

波形は 2 倍オーバーサンプリングと polyBLEP で作り、折り返しノイズを抑えています。
チップの外で掛けているのは、ディレイ、薄いリバーブ、テープ風の処理
(揺れ、ヒス、音飛び、停止) とマスタリングだけです。

歌声は入っていません。歌は矩形波が担当していて、歌詞は旋律の音符と 1 モーラずつ対応させてあります
(`dist/kago.json` と `dist/kago.mid` に時刻つきで入っています)。

## 作り直す

Python 3.10 以降と numpy があれば動きます。MP3 への変換には ffmpeg を使います。

```sh
python3 render.py            # dist/kago.wav, kago.mp3, kago.mid, kago.json
python3 render.py --stems    # チャンネル別の WAV も dist/stems/ に
python3 tools/build_player.py   # player/index.html を作り直す
```

譜面を直したあとの点検用に、和声のぶつかりを探す `tools/lint.py` と、
ピアノロールやスペクトログラムを画像にする `tools/view.py` (Pillow が必要) があります。

## 再生ページ

`player/index.html` は、歌詞を譜割りどおりに表示しながら再生するページです。
ファイルを直接開くのではなく、リポジトリの直下で簡易サーバを立てて開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/player/
```

## ファイル

```

chip/synth.py      オシレータと 1 音ぶんのレンダリング
chip/mml.py        MML パーサ
chip/song.py       区間・テンポ・ステムのレンダリング
chip/fx.py         ミックス、ディレイ、リバーブ、テープ風の処理、マスタリング
chip/midi.py       MIDI 書き出し
render.py          書き出し用のコマンド
player/            再生ページ (template.html が元、index.html は生成物)
tools/             点検と可視化
dist/              書き出したもの (WAV とステムは .gitignore)
```

## 補足

旋律、和声、編曲、歌詞はすべてこの曲のために書いたもので、既存の曲からの引用はありません。
C メロの歌詞は、わらべうた「かごめかごめ」の言い回しを踏まえています。
